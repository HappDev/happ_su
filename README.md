Happ — кроссплатформенное приложение для удобной работы с прокси-серверами. Построенное на базе мощного ядра Xray, оно доступно на Windows, macOS, Linux и мобильных устройствах. Интуитивный интерфейс и гибкие настройки делают Happ надёжным инструментом как для новичков, так и для опытных пользователей.

**Основные возможности включают:**

* Настройку прокси-серверов на основе гибких правил маршрутизации.
* Поддержку множества современных протоколов, включая:
  * **VLESS (Reality)**
  * **VMess**
  * **Trojan**
  * **Shadowsocks**
  * **Socks**

**Happ** гарантирует конфиденциальность вашей сетевой активности, не собирая никаких данных. Вся информация остается исключительно на вашем устройстве и не передается на сторонние серверы.

Важно отметить, что **Happ** не содержит серверов и не предоставляет услуги VPN. Пользователи самостоятельно производят настройку своих серверов в личных целях. Также Happ просить своих пользователей соблюдать действующие законы своей юрисдикции при использовании приложения.
