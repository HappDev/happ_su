# Ping

应用支持三种 Ping 类型：**ICMP**、**TCP** 和 **代理方式 (via Proxy)**。

**ICMP Ping**

使用 ICMP 数据包（类似终端中的 `ping` 命令）。\
由于需要临时关闭隧道来进行测试，因此使用不够方便。

**TCP Ping**

通过直接向服务器发送 TCP 包来测量延迟。\
无需关闭隧道。\
但在使用 CDN 的情况下，结果可能不准确，因为测得的是到最近 CDN 节点的延迟，而非最终服务器。

**代理方式 Ping (via Proxy Ping)**

通过活动的 VPN 隧道进行完整链路测试，包括连接目标服务器的所有步骤。\
这是最准确、最能真实反映连接情况的方法，包括 TLS 握手等过程。

**via Proxy Ping 的执行过程示例：**

1. 解析服务器域名（如果连接点是以域名形式提供的）。
2. 建立与服务器的 TCP 连接。
3. 如果启用了 TLS，则建立 TLS 连接。
4. 由服务器端解析测试目标的域名。
5. 如果目标站点为 HTTPS，服务器建立 TLS 连接。
6. 接收并测量来自测试站点的响应。
